# NumPy Data Explorer

## Objective
To learn and demonstrate NumPy fundamentals for numerical data analysis.

## Technologies Used
- Python
- NumPy
- Jupyter Notebook

## Features
- Array Creation
- Indexing and Slicing
- Mathematical Operations
- Statistical Operations
- Axis-wise Operations
- Reshaping
- Broadcasting
- Save and Load
- Performance Comparison

## Learning Outcome
Learned how NumPy can be used for efficient numerical computation and basic data analysis.
