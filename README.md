# NumPy Data Explorer

## Project Title

**NumPy Data Explorer – Student Marks Analysis**

## 1. Objective

The objective of this project is to understand and demonstrate basic data analysis operations using NumPy.

The project analyzes student marks using NumPy arrays and performs mathematical and statistical calculations.

## 2. Technologies Used

* Python
* NumPy
* Jupyter Notebook

## 3. Project Features

* Create and work with NumPy arrays
* Store student marks using NumPy
* Perform mathematical operations
* Calculate Mean
* Calculate Median
* Calculate Maximum marks
* Calculate Minimum marks
* Calculate Standard Deviation
* Perform basic data analysis
* Save and load NumPy data using `.npy` file

## 4. How to Run

1. Install Python.
2. Install the required libraries using:

```bash
pip install -r requirements.txt
```

3. Open Jupyter Notebook.
4. Open `numpy_data_explorer.ipynb`.
5. Run all cells.
6. View the calculated results and analysis.

## 5. Files Description

| File                        | Description                                         |
| --------------------------- | --------------------------------------------------- |
| `numpy_data_explorer.ipynb` | Main Jupyter Notebook containing the NumPy analysis |
| `marks.npy`                 | NumPy file containing student marks data            |
| `requirements.txt`          | Contains the required Python libraries              |
| `README.md`                 | Documentation and information about the project     |

## 6. Sample Output / Results

The project performs basic statistical analysis on student marks.

Example results include:

* **Mean:** Average marks of students
* **Median:** Middle value of the marks
* **Maximum:** Highest marks obtained
* **Minimum:** Lowest marks obtained
* **Standard Deviation:** Variation in student marks

The results are displayed directly in the Jupyter Notebook.

## Conclusion

This project demonstrates how NumPy can be used for efficient numerical operations and basic data analysis using Python.
